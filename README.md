# LadderH2H

Head-to-head comparison of two TrackMania United Forever logins across every official track, powered by the [UnitedLadder API](https://api.ul.unitedascenders.xyz/docs).

Enter two logins to see a W – D – L record, a stats table, and a track-by-track breakdown with exact times on demand.

Static site (plain HTML/CSS/JS) — no build step. Open `index.html` or serve the folder with any static server.

Not affiliated with UnitedAscenders.
